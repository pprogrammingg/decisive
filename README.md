# Decisive

Used for athletic decision making drills, it is a single `index.html` page that cycles random full-screen colours with a customizable delay between changes, with no build step or dependencies and solid behaviour on mobile browsers.

## How to run

Open `index.html` in a browser (file or any static host). For a quick local server:

```bash
python3 -m http.server 8080 --bind 127.0.0.1
```

Then visit `http://127.0.0.1:8080/` in that directory.
